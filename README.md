# Smokey-Operations-
Integrated Business Operations Management Platform

A front-end demo of an end-to-end operations platform for a multi-location food business, from the customer order through to the kitchen, dispatch and the books.
Smokey OS shows how one operating model can give a founder, an outlet manager and a kitchen lead visibility into the same business. Demand, production, stock, delivery and finance sit in one interface, with a location switcher for filtering by branch.
